# HDR signalling

What a stream's HDR is taken for, and when a change of it resets the HDMI link:
Dolby Vision the container does not declare, HDR10+ removed for the sink, and
HDR changes that leave the link as it is, in HFR VRR 3D as elsewhere. They
build on the HDR10+ to Dolby Vision conversion in `20-coreelec-ports` and on
the 3D output patches, so the group sits after both.
