# These builds

What makes an installed build one of these rather than stock CoreELEC: it
knows where these builds are published, and where to report a problem with
them; and it comes with our add-on repository (allolive/kodi_addons)
installed and trusted like Kodi's and CoreELEC's own.

They also come with our skin, which a new profile starts on (Estuary stays
the one Kodi falls back to), the speech add-on the subtitle realignment
listens with, and the 3D glasses add-on - each from a release of that
repository, enabled, and updated from it like the rest.
